# The Living Archive — 8-Planet Distinct Video Experience

An interactive deep-space celestial chronicle and cinematic 3D planetary observatory.

**Executive Architect**: Tanmay (Adesh Srivastava)

## Features
- **8 Dedicated HD Videos**: Independent footage for Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus, and Neptune
- **3D Perspective Portal**: Mouse-tilted destination window projecting live next-planet stream
- **Procedural Web Audio**: Electromagnetic resonant frequencies tuned to NASA planetary data
- **Modern Responsive Stack**: Butter-smooth 60-120 FPS performance across desktop and mobile
