## 🌟 Overview

An immersive, cinematic web platform celebrating the **BMW i7 Sedan & 7 Series**. Built with a futuristic dark aesthetic, interactive 3D engineering cutaways, 4K authentic vehicle photography, and smooth scroll choreography designed for high performance and zero-lag responsiveness.

---

## 🚀 Key Features

- 🏎️ **Interactive 3D Hardware Anatomy**: Explore real OEM BMW engine blocks, 5th-Gen eDrive synchronous motors, and adaptive dual-axle air suspension cutaways.
- 🎬 **Official 4K Cinematics**: High-bitrate 4K driving sequences, night city dominance captures, and real showroom color variants.
- 🌌 **Executive Sanctuary Tour**: 31.3" 8K BMW Theatre Screen preview, Sky Lounge Panoramic Glass Starlight roof, and Bowers & Wilkins Diamond 4D Surround audio specs.
- ⚡ **Real-Time Configurator**: Dynamic exterior paint selector (Carbon Black, Mineral White, Oxide Grey) with real-time powertrain telemetry.
- 🔇 **Pure Silent Luxury**: Sound-free, zero-audio design optimized for smooth, distraction-free executive browsing.
- 🔒 **Cryptographic Authorship Seal**: Salted verification hash preserving authentic project creation rights.

## ⚡ Quick Start & Execution

### Run with VS Code Live Server (Zero Configuration)
No Node.js or terminal build commands needed:
1. Open this project in **VS Code**.
2. Right-click on **`BMW-Web/index.html`**.
3. Select **"Open with Live Server"** (or click **Go Live** on the bottom status bar).
4. The website will open immediately at `http://127.0.0.1:5500/BMW-Web/index.html`!
